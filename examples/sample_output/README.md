# Sample output

Everything here was generated by the scripts in this repository from the synthetic
data in `examples/` — no editing, no touch-ups. Open any of it to see what the tool
actually produces before installing anything.

| File | What it is |
|---|---|
| `fmv_review_filled.xlsx` | The review workbook, filled. Open it and check the formula bar: the blended survey row, percentile callouts, and Δ row are live formulas, not pasted values. |
| `review_packet.docx` / `.pdf` | The committee packet. Eight sections, market-band exhibit, cohort totals. |
| `review_packet.csv` | Flat audit extract of the cohort table. |
| `email_report.html` | Self-contained email report — open it in a browser, or paste it into an email. The chart is embedded, so nothing breaks when it's forwarded. |
| `email_report.pdf` | The same report exported with 0.6" margins. |
| `new_hire_range/` | The new-hire pack: market-anchored range, exhibit, and machine-readable summary. |

The provider names are `Provider 1/2/3` and `Candidate A`, and the survey sources are
`Survey 1/2/3`. Nothing here reflects a real person, organization, or licensed survey.

To regenerate all of it:

```bash
python3 scripts/fmv_workbook_generator.py --name "Provider 1" \
  --salary-file examples/example_salary_file.xlsx \
  --survey-file examples/example_survey_combined.xlsx \
  --template examples/example_fmv_template.xlsx \
  --proposed-base 325000 --stipend 42000 --wrvu 4228 --track-num 100026 \
  --output examples/sample_output/fmv_review_filled.xlsx

python3 scripts/build_adjustment_report.py --name "Pediatric Critical Care Faculty" \
  --providers-file examples/example_cohort.tsv \
  --market-anchors-file examples/example_anchors.json \
  --output examples/sample_output/review_packet.docx
```
